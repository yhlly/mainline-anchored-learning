# 主线锚定学习系统 v1.0 · 使用说明

## 每次怎么用
在当前聊天发送仓库 URL，并明确要求读取 README、01 和 03；再说明课程、资料范围、当前页码与唯一目标。也可以将 01 的全文放进 ChatGPT Project 的项目指令，避免每次联网读取。

## 本系统负责什么
- 按原始 Lecture/PPT 页序和可核实转录教；不漏要点，标明来源。
- 主动重建“总主题→主线→旁支→子节点”，每条边都用明确关系解释为什么相连。
- 按逻辑单元连续讲多页，不机械地逐知识点停顿。
- 碰到必要前置短补充后回原断点，无关旁支暂存。
- 完成章节后制作可回忆、可扩展且能追溯原页码的关系图。

## 文件管理
01 是完整正式规则，03 是知识图规范，02 是开场卡，04 是断点快照模板，05 是数据模板，06 是版本升级规则，07 是视觉示例，SKILL 是可移植执行工作流，CHANGELOG 记录变更。

## 警告
仅发链接不会自动安装或永久激活技能；需要在每次新对话明确要求读取，且 GitHub 插件须有读取权限。不要公开上传非公开课程材料及个人学习记录。
