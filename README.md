# 主线锚定学习系统（Mainline-Anchored Learning）

> v1.0 · 可扩展、事实优先、原 Lecture 顺序忠实

这是可复用的学习工作流：**按原课件顺序学习，按真实逻辑重建关系，沿一条醒目主线高效推进，并管理学习断点**。

## 一键使用
在能读取本仓库的 ChatGPT 对话里发送：

`请先读取 https://github.com/yhlly/mainline-anchored-learning 的 README.md、01_项目长期指令.md 和 03_知识图谱与思维导图规范.md，然后按照最新规则教我 [课程/页码]。`

**重要**：单独粘贴 GitHub 链接并不保证每次对话自动加载完整规则；需要明确要求读取，且当前会话有权限访问仓库。使用 ChatGPT Project 时，也可以把核心指令复制进 Project instructions。

## 使用原则
- 原文顺序和页码不丢；知识关系真实，不强造因果。
- 主线尽可能笔直、醒目；补充与例子作为侧支。
- 一次学完完整逻辑单元，避免每个知识点停一次。
- 内容与规则均可增量扩展；保留学习状态。
