# Mainline-Anchored Learning (v1.0)

This document is an execution guide, not proof of automatic installation as an app Skill.

Read [the canonical teaching protocol](./01_项目长期指令.md), [knowledge map standard](./03_知识图谱与思维导图规范.md), and [change management rules](./06_扩展与版本管理.md).

Follow source order and original page references. Reconstruct the factual logic as a central mainline with side branches, explain the meaning of each relationship, and never invent causality to make a diagram prettier. Teach efficiently in connected multi-page logical units. Protect the learning goal from unnecessary tangents. Create an expandable full-chapter concept map and source-page index when requested. Resume learning from an explicit checkpoint. Prioritize accuracy over diagram geometry.

Commands: 继续; 回主线; 暂停存档; 更新关系图; 查漏; 慢一点; 多讲一些.
